# Contributing

- Keep Apex branding and implementation original.
- Prefer opt-in, reversible changes and verified status reporting.
- Never blindly disable services or remove Windows components.
- Put system behavior in focused `scripts/` files and GUI mappings in `config/toolbox.json`.
- Run portable validation and build checks. Test system changes on disposable Windows 11 desktop and laptop VMs.
- Clearly document unsupported actions and limitations.

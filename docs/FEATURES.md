# Feature status

Implemented actions are listed in `config/toolbox.json` and launch separate PowerShell scripts. The Toolbox includes compatibility gating, action progress, confirmation prompts, a skippable first-run flow, and navigation for all requested categories. Power profiles clone Windows Balanced, apply limited processor policies, and can restore the previously selected plan; created plans remain installed. RAM Saver has detectable OFF/BALANCED/AGGRESSIVE states backed by a per-user policy, not memory-cache clearing. Driver and network diagnostics, Windows Update driver search, component inventory, WebView2/Edge distinction, and system reports are implemented. Repair Center covers selected DISM/SFC/update-cache/Installer operations plus diagnostics for Game Services, Xbox sign-in, Explorer, and WinRE. No script automatically reboots Windows.

Optional current-user consumer-app and Store removal is allowlisted and confirmed; Store restore depends on the original manifest remaining available. Edge is not removed; Chrome and NanaZip actions use Windows settings rather than editing protected default-app hashes. Wallpaper, dark/light theme, transparency, startup inventory/settings, search/indexing, and GPU preference settings are available. Automatic driver reinstall, broad service/privacy tuning, ISO generation, and some requested UI controls remain unimplemented. Windows 11 26H2 and physical hardware require testing on corresponding Windows installations.
